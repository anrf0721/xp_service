# xp-owner-min

本目录只验证一件事：模型调用只读工具之后，回复结果是否只含允许字段，以及工具是否被准确调用。

## 权威

- `session-facts`：会话事实。决定候选能不能发布。
- `run-facts`：运行记录。只提出并记录候选，不发布。
- `person-vehicle`：预先存在的凭证种类。没有 VIN 绑定。
- `appointment-status`：进程内预约记录。只有只读函数，不是外部查询接口。

## 本步不做

- 远程控车
- 发起救援
- 创建或修改维保预约
- 修改交付单
- 写入家充工单
- 用政策文本回答“这台车当前在保”
- 外部模型调用接口
- 对接真实小鹏售后系统的预约维保查询接口
- 网络推送投递接口
- 切换 VIN 入口
- 账号与人车关系在线查询接口
- VIN 绑定表
- 凭证签发接口
- 发布裁决表作为跨权威依据复核

发布裁决表只记录客服系统自己的会话裁决。`basis_rechecked` 固定为 0。它不能证明预约记录在发布时仍然有效。
